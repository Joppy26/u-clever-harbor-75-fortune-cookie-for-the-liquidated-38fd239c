One fortune cookie line for a crypto trader who has just been liquidated:
a classic fortune opening ("Your luck is about to change") that lands on
the loss with a double meaning ("kept the change"). Rueful, warm, and
short enough to read in a single breath.

Run `python3 main.py` and it writes the fortune to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (or `/output` by default).
